# Quran translation snapshots

Aaris keeps complete ayah translations as immutable, hash-pinned source snapshots. Ordinary
builds are fully offline: the checked-in source vault is validated first and then compiled into
an independent SQLite translation layer.

`catalogue.json` retains the display metadata for every edition. All installed editions must
cover exactly 6,236 canonical Quran coordinates with non-empty source text. The Arabic corpus is
independent and is never replaced by Arabic supplied by a translation provider. Word-gloss
concatenation and machine translation are not used as a scholar's full ayah translation.

## Rights and attribution

QuranEnc publisher terms were checked 2026-09-25 and are recorded in the manifest/notice. They
permit republication subject to source/publisher credit, version identification and the other
conditions documented by QuranEnc; they are not treated as an unrestricted perpetual grant.

Tanzil translation terms were checked 2026-09-26 at https://tanzil.net/trans/. Tanzil lists
Fateh Muhammad Jalandhry as the Urdu translator and provides translations for non-commercial use;
commercial use requires the necessary translator/publisher permission. Aaris therefore keeps this
edition inside the repository's existing NON_COMMERCIAL_PREVIEW distribution scope. The archived
translation is reproduced verbatim; Aaris does not claim public-domain status or rewrite the text.

If distribution terms or project monetization change, the affected edition must be reviewed
before release. Source updates are acquired separately, diff-reviewed, hash-pinned and then
repinned. A normal app build never reaches the network.

Urdu-to-Devanagari/Roman display editions are not supplied. Urdu generally omits short vowels, so
a character replacement cannot reliably preserve pronunciation. An unreviewed conversion must
not be attributed to the original translator.

The independent SQLite layer is generated by `tools/build_translations.py`, invoked by the
existing local content builder. Source-file hashes and complete coordinate coverage are mandatory.
The generated pack has its own runtime checksum.
