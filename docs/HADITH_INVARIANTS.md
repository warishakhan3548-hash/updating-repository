# Hadith Integrity Invariants

For every production Hadith pack:

- record identity is unique and edition-specific;
- collection, book/chapter, source edition and numbering scheme are explicit;
- original Arabic is preserved separately from search representations;
- grade is an attributed assertion with grader, source and source version;
- parallel records are never physically merged;
- source-to-canonical mappings carry confidence;
- uncertain mappings cannot silently alter learning state;
- source artifact checksum and licence snapshot pass the Source Vault gate.

A dataset that lacks reliable edition or numbering provenance remains a Research Candidate even when its text is useful for search evaluation.
