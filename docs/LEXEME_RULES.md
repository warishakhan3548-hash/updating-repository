# Lexeme and Sense Rules

1. Preserve source token and morphology assertions.
2. Map tokens to app-owned lexemes only with an explicit mapping rule/version.
3. Represent contextual meaning as `Sense`, not as the lexeme itself.
4. Keep occurrence-level uncertainty.
5. Prefixes/clitics may become grammar units instead of duplicate vocabulary cards.
6. Verb-form distinctions must not be collapsed when they change learning meaning.
7. Particle identity should include grammatical/semantic function where the source supports it.

The proposed QAC-specific mapping rule remains a hypothesis until the exact QAC 0.4 artifact and field semantics are imported and validated. Do not hard-code it before that verification.

Learning cards are semantic units, not raw source rows.
